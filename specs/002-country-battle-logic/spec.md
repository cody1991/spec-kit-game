# Feature Specification: 国家攻占规则调整

**Feature Branch**: `002-country-battle-logic`  
**Created**: 2025-11-30  
**Status**: Draft  
**Input**: User description: "1. 不要有东南亚，北美，中美这些集合概念。都用国家来表示。 2. 另外攻占别人的国家，是一个国家一个国家来进行进攻的，而不是一次性全部占领。 3. 另外占领了一个地方，原来的人名要消除渲染，不然名字会重叠。"

## User Scenarios & Testing _(mandatory)_

### User Story 1 - 逐个攻占对手国家 (Priority: P1)

作为一名玩家，我希望在攻占其他玩家时是「一个国家一个国家」地依次发起进攻，而不是一次性把对方所有国家全部占领，这样我可以根据每一场战斗的结果调整策略，并在过程中做出战术选择，而不是被一次性结算锁死局面。

**Why this priority**: 单个国家粒度的攻占规则是本次玩法改动的核心，直接影响战斗节奏、公平性和玩家的策略空间，如果仍然一次性占领全部国家，会和本次需求目标相违背。

**Independent Test**: 只实现「按国家逐个攻占」这一能力，也可以完整跑一局游戏，通过多次发起对单个国家的攻占、结算结果、重复多轮来验证规则生效且可玩。

**Acceptance Scenarios**:

1. **Given** 玩家 A 拥有多个国家，玩家 B 也拥有多个国家，**When** 玩家 A 在地图上选择玩家 B 的一个具体国家并发起攻占，战斗结算为胜利，**Then** 只有该被选中的国家变更为玩家 A 所有，玩家 B 的其他国家保持原有归属不变。
2. **Given** 玩家 A 在同一回合内连续两次分别选择玩家 B 的两个不同国家发起攻占，**When** 每一次战斗分别结算，**Then** 每次只影响对应目标国家的所有权，其它国家不因这一结算被连带占领或失去。

---

### User Story 2 - 地图按国家展示归属 (Priority: P2)

作为一名玩家，我希望地图上的占领信息都是以「国家」为单位展示，而不是出现「东南亚」「北美」「中美」这类集合区域概念，这样我能一眼看出每个国家的真实归属，理解自己的势力范围，而不会被区域聚合概念干扰判断。

**Why this priority**: 展示层的单位必须和攻防规则保持一致，否则玩家会看到「区域」被占领，但规则又按国家结算，认知会严重错位，影响理解和决策。

**Independent Test**: 在不改动其他玩法的前提下，仅启用按国家展示归属（移除区域级展示），即可独立测试：地图上不再出现区域级占领节点，所有显示均为国家级别。

**Acceptance Scenarios**:

1. **Given** 游戏中原本存在「东南亚」「北美」「中美」等区域级占领或展示单元，**When** 玩家进入世界地图或国家列表界面，**Then** 不再出现上述区域名称作为可被占领或展示归属的单位，而是看到对应区域内的每个国家分别显示归属玩家。
2. **Given** 玩家浏览自己和对手的势力范围，**When** 查看地图或相关信息面板，**Then** 每个国家只显示当前占领者，且没有区域级的额外占领条目让总数重复或混淆。

---

### User Story 3 - 占领后只显示当前占领者姓名 (Priority: P3)

作为一名玩家，当我成功占领一个国家时，我希望该国家上只显示当前占领者的名字或标识，而不会和原来占领者的名字重叠在一起，这样我可以清晰地看到当前归属，不会被两个名字叠在一起误导。

**Why this priority**: 名字重叠会直接影响地图可读性，玩家可能误判当前归属，甚至认为存在异常或 bug；虽然不如规则本身重要，但属于体验上必须修复的问题。

**Independent Test**: 在不依赖其它新功能的前提下，只需测试多次占领、易主的场景，即可验证任意时刻每个国家上最多只展示一个玩家姓名或标识，且总是当前占领者。

**Acceptance Scenarios**:

1. **Given** 国家 X 当前显示玩家 B 的名字，**When** 玩家 A 攻占国家 X 并结算胜利，**Then** 地图上与国家 X 绑定的位置只显示玩家 A 的名字或标识，不再显示玩家 B 的名字，也不存在两者叠在一起的情况。
2. **Given** 国家 X 在一局游戏中多次在不同玩家间易主，**When** 玩家在任意时间点查看地图，**Then** 国家 X 上始终只显示当前占领者的名字，历史占领者的名字不会残留或重影。

### Edge Cases

- 当玩家通过 UI 一次性选择多个国家尝试发起攻占时，系统应强制用户最终只能对单个目标国家确认攻占动作，避免任何「一键占领全部国家」的入口。
- 当某个玩家已经失去所有国家（被淘汰）而仍被选择为攻击目标时，系统应阻止该操作并给出明确提示，不允许对不存在国家列表的玩家发起攻占。
- 当同一个国家在短时间内被连续多次攻占（例如一局内频繁易主）时，系统需要保证每次结算后的展示都只保留最后一次结算产生的占领者姓名，不会叠加历史层。

## Requirements _(mandatory)_

### Functional Requirements

- **FR-001**: 系统必须以「国家」作为最小占领与展示单位，移除「东南亚」「北美」「中美」等集合区域作为可被占领或单独展示归属的概念。
- **FR-002**: 在任何展示玩家势力范围的界面（例如世界地图、国家列表、战报中涉及占领信息的部分），每个可见节点必须是具体国家，而不是区域集合标签。
- **FR-003**: 发起攻占时，系统必须要求玩家明确选择一个且仅一个目标国家，不提供或保留任何可以一次性对同一玩家全部国家发起攻占的操作入口或流程。
- **FR-004**: 当对目标国家的攻占结算为胜利时，系统只改变该目标国家的所有权，不会因为本次结算而自动改变目标玩家的其他国家所有权。
- **FR-005**: 当国家的占领者发生变化时，系统必须立即更新该国家的展示信息，使其只显示新的占领者姓名或标识，并完全移除原占领者姓名在该国家上的渲染。
- **FR-006**: 对同一国家发生多次易主时，每一次所有权变更都必须覆盖之前的展示结果，确保任意时刻该国家上最多只存在一个玩家名字或标识，无重影、无重叠。
- **FR-007**: 当玩家重新进入对局或刷新世界地图时，所有国家的所有权与展示都必须与当前最新的占领状态一致，不出现区域级占领条目或过期的名字残留。

### Key Entities _(include if feature involves data)_

- **玩家（Player）**: 游戏中的参与者，具有唯一标识、展示用名称（或昵称）、当前已占领国家列表等属性，用于计算势力范围与胜负条件。
- **国家（Country/Territory）**: 世界地图上的最小占领单位，具有名称、所属地理区域（仅作地理分组展示，不再作为占领单位）、当前占领者玩家引用、在地图上的展示位置等属性。
- **攻占事件（Conquest Event）**: 一次针对单个国家的攻占行为，包含发起方玩家、被攻占国家、原占领者玩家、战斗结算结果以及结算后新的所有权，用于驱动地图状态和展示的更新。

### Assumptions & Constraints

- 本次改动只调整占领单位和展示规则，不改变战斗结算算法本身（例如如何计算胜负、战力消耗等），这些沿用现有规则。
- 世界地图中可能仍存在区域概念用于分组或筛选，但这些区域不再作为可被占领或展示归属的独立实体，只起到分组与导航作用。
- 一局游戏中不会出现国家被拆分成更小单位（例如城市或省份）的情况，国家始终是最小占领粒度。
- 多人同时对同一国家发起攻占的并发或冲突场景，沿用现有系统的先后顺序或仲裁机制，本规格只要求最终结果对应一个明确占领者并正确展示。

## Quality Guardrails _(per Constitution)_

- **Code Quality**: 本特性在实现时需遵守项目既有的代码质量标准，包括统一格式化、静态检查和必要的内嵌文档说明；合入前需通过现有质量门禁，并在变更说明中清晰描述规则变更点（按国家粒度、移除区域占领、名称覆盖规则）。
- **Testing Evidence**: 为上述每个用户故事和关键边界场景补充或新增自动化测试（例如按国家攻占、禁止批量占领、名称覆盖），并在持续集成流程中运行；测试结果需能证明在多轮攻占和多局对战中规则保持一致且无回归。
- **User Experience**: 在测试和验收中观察玩家对世界地图的理解程度，重点验证是否能快速看清每个国家的当前归属；通过简单的问卷或访谈确认玩家不再混淆区域概念和国家占领，并认为占领结果一目了然。
- **Performance & Observability**: 确保按国家粒度更新占领信息不会导致地图刷新或状态切换时出现明显卡顿；通过现有日志或埋点记录关键攻占事件（例如国家所有权变更次数），便于后续分析是否存在异常连锁占领或展示错误。

## Success Criteria _(mandatory)_

### Measurable Outcomes

- **SC-001**: 在功能上线后的回归测试中，抽样至少 50 次对单个国家的攻占行为，100% 情况下只会改变该目标国家的所有权，不会出现一次操作占领或丢失多个国家的情况。
- **SC-002**: 在全面检查当前地图所有国家时，不再出现「东南亚」「北美」「中美」等区域级占领节点，且每个国家都能看到明确的当前占领者；人工抽查全部国家时，错误或缺失展示比例低于 1%。
- **SC-003**: 在至少 30 组多次易主的国家样本中，任意时间点地图上每个国家最多只显示一个玩家名字或标识，未发现名称叠加或残留现象。
- **SC-004**: 在内测或灰度数据中，通过简单问卷或访谈收集到的反馈显示，至少 80% 的受访玩家认为「现在更容易一眼看清自己和对手各自占领了哪些国家」，相较于改动前主观可读性有明显提升。
